# 9scorp4.github.io

> *un jardín cibernético — a cybernetic garden*

A personal observatory: field notes, generative sketches, and research dispatches from someone who reads ecologies for a living. A place where ideas can be in-progress and the aesthetic is allowed to be weird.

## What lives here

- **el ahora · the now** — a current dispatch log, updated whenever there's something to say
- **el invernadero · the conservatory** — a gallery of generative p5.js sketches
- **cuaderno de campo · field journal** — long-form notes on cybernetics, anthropology, and adjacent puzzles
- **los cultivos · cultivations** — projects in active growth, dormant, or wild
- **la biblioteca · the library** — the authors of the in-absentia documentation
- **libro de visitas · visitors' book** — an optional console for people who like to type

## Stack

Astro, deployed to GitHub Pages. See [`docs/STACK.md`](docs/STACK.md) for the full picture.

## Building locally

```bash
git clone https://github.com/9scorp4/9scorp4.github.io
cd 9scorp4.github.io
npm install
npm run dev
```
